## 摘要
在无人机中继的移动边缘计算网络中，计算任务产生的流量具有不同的延迟要求和数据大小。因此，路由决策需要同时适应流量特征和不断变化的网络条件。与单路径路由相比，多路径路由更适合这种异构流量，因为它提供多种转发选项并支持灵活的流量分流。然而，传统的多路径路由通常在预定义的端到端路径上分流流量，难以快速响应无人机网络中的链路波动和拓扑变化。为解决这一问题，我们提出了一种适用于多跳无人机网络的流量自适应逐跳多路径路由方法，其中每架无人机在多个候选下一跳之间动态分配流量。我们将路由问题建模为在降低丢包率的同时提高按时分组投递率的优化问题，并将其建模为分散式部分可观测马尔可夫决策过程。为了解决这个问题，我们开发了一种多智能体强化学习算法，称为基于狄利克雷建模的多智能体近端策略优化。MAPPO-DM遵循集中训练与分散执行的框架，并使用狄利克雷分布对连续流量分流动作进行建模。仿真结果表明，MAPPO-DM优于基线方法，并在各种网络条件下保持稳健的性能。

## Abstract
In uncrewed aerial vehicle (UAV)-relayed mobile edge computing (MEC) networks, computation tasks generate traffic with diverse latency requirements and data sizes. Routing decisions therefore need to adapt to both traffic characteristics and changing network conditions. Compared with single-path routing, multipath routing is better suited to such heterogeneous traffic because it provides multiple forwarding options and enables flexible traffic splitting. However, conventional multipath routing usually splits traffic over predefined end-to-end paths, making it difficult to respond quickly to link fluctuations and topology changes in UAV networks. To address this issue, we propose a traffic-adaptive per-hop multipath routing method for multi-hop UAV networks, in which each UAV dynamically distributes traffic among multiple candidate next hops. We formulate the routing problem to improve the on-time packet delivery ratio while reducing the packet loss ratio, and model it as a decentralized partially observable Markov decision process (Dec-POMDP). To solve this problem, we develop a multi-agent reinforcement learning (MARL) algorithm, termed Multi-Agent Proximal Policy Optimization with Dirichlet Modeling (MAPPO-DM). MAPPO-DM follows the centralized-training-and-decentralized-execution framework and models continuous traffic-splitting actions using a Dirichlet distribution. Simulation results show that MAPPO-DM outperforms the baseline methods and maintains robust performance under various network conditions.

## 2. 论文提出的方法论

### 2.1 核心思想

每架 UAV 作为一个智能体，在仅依赖本地观测的条件下，将当前最高优先级非空子队列中的分组，按连续比例动态分配于多个候选下一跳（以及本地保留），实现逐跳、多路径、流量感知的路由决策。

### 2.2 系统建模与关键公式

- **网络模型**：UAV 分为热点（hotspot）、网关（gateway）、中继（relay）、常规（regular）四类，任务生成概率满足 p_hot > p_reg > p_rel > p_gat。
- **通信模型**：UAV-UAV 采用 LoS 信道模型，UAV-GBS 采用 LoS/NLoS 混合概率模型；每个 UAV 最多维护 N 个候选下一跳链路和一条直达 GBS 链路，每链路发射功率均分。
- **候选下一跳选择**：仅保留满足 SINR 阈值且地理上更靠近 GBS（防环）的邻居，并按地理转发得分降序取前 N 个。
- **队列模型**：每 UAV 通信缓冲区分为高、中、低三个优先级子队列，按剩余期限（≤4.5s、≤9s、>9s）将流量分配至对应子队列；每时隙优先转发最高优先级非空子队列。
- **转发模型**：若可直连 GBS 则直接发送；否则执行流量拆分动作 a_m(t) = [a_m,0(t), a_m,1(t), …, a_m,N(t)]，满足归一化约束 Σa = 1，且各接收端需满足链路容量与接收方缓冲区约束（式 9–12）。
- **优化目标**（P1）：最大化 η_pack − φ_loss，即按时分组投递率与丢包率之差。

### 2.3 Dec-POMDP 建模

- 将路由问题建模为 **Dec-POMDP**：M（UAV智能体集合）、S（全局图状态）、O_m（局部观测）、A_m（流量拆分动作）、P（状态转移）、R（共享奖励）。
- **观测空间**：流量特征向量（选中队列长度 + 紧迫度）+ 各候选邻居特征（有效指示、地理进步、容量需求匹配度、接收方可用缓冲区、上游邻居数），邻居按 ID 升序排列、不足补零。
- **全局状态**：以图 G(t) = (V, E(t), X(t), E(t)) 表示，包含节点特征（队列占用/空闲、紧迫度、上下游邻居数、GBS可达性、角色等）与边特征（方向指示、地理进步、估计/实际容量、接收方缓冲区、SINR）。
- **奖励函数**：由本地路由奖励（地理进步增益 − 拥塞风险惩罚 − 丢包惩罚 + 本地持有惩罚）与网络级事件奖励（按时到达加分、错过期限扣分，按有效 UAV 数均分）组成。

### 2.4 MAPPO-DM 算法

- **整体框架**：集中训练 + 分布式执行。所有 UAV 共享相同的 Actor 参数。
- **Actor 网络结构**：
  - Transformer 编码候选邻居间的交互关系（mask 无效位置，不使用位置编码）；
  - GRU 捕获本地网络状态的时间演化；
  - 流量特征经 MLP 编码后与 GRU 时序隐状态拼接为决策上下文；
  - 可学习的 holding token 与邻居 token 经打分网络产出未归一化分数，masked softmax 得到均值流量拆分向量 μ(t)；
  - 另设浓度估计网络输出总浓度参数 κ(t)，构造 **Dirichlet 分布** Dir(α(t))，其中 α_n(t) = κ(t)·μ_n(t)。训练时从该分布采样动作以探索，测试时直接使用均值 μ(t) 确定性执行。
- **Critic 网络结构**：
  - 基于全局图状态，采用边感知多头图注意力网络（LC_GAT 层），注意力打分同时考虑节点状态兼容性与链路属性；
  - 经全局注意力池化获得图级表示，与节点表示、流量特征拼接后输出各 UAV 的状态值估计。
- **策略优化**：
  - 采用 PPO 裁剪目标 + GAE 优势估计；
  - Actor 损失含熵正则项；Critic 采用值函数裁剪 + 单步 TD 目标；
  - 完整训练流程见 Algorithm 1（N_epi = 1000 个 episode，每 episode T_max = 120 个时隙，每轨迹 N_upd = 2 次 PPO 更新）。
- **在线复杂度**：每 UAV 每时隙的 Actor 前向复杂度为 O(N·C_MLP(neighbor) + C_Transformer + C_GRU + …)，通信开销仅为轻量邻居信息交换。

## 3. 实验设计

### 3.1 场景设置

- 三维 UAV 网络，水平覆盖 1200m × 1200m，GBS 固定于 [0,0,−100]m。
- 采用三维 Gauss-Markov 移动模型（速度范围 [15,15,5]–[50,50,20] m/s）。

- 任务生成：热点 0.085/时隙、常规 0.015、中继 0.0065、网关 0.0045；每任务 1.0–2.0MB 数据，分组 1500B，期限 8–14s。
- 未使用标准公开数据集，而是基于自建仿真环境（PyTorch 实现）。

### 3.2 对比的基准方法

1. **Priority-Aware Greedy Single-Path**：启发式逐跳单路径，紧急流量选最靠近 GBS 的邻居，否则选容量最大的邻居。
2. **Equal-Split Per-Hop Multipath**：在全部下游邻居间均分流量。
3. **Capacity-Aware Per-Hop Multipath**：按候选邻居可用容量比例分配流量。
4. **I-AOMDV-Guided Per-Hop Multipath**：借鉴端到端多路径协议 I-AOMDV 的路径评分，将路径分数映射为逐跳分流权重（每 10 时隙更新）。

### 3.3 消融实验

- **w/o Graph Critic**：图注意力 Critic 替换为 MLP-based 分散 Critic。
- **w/o Transformer**：Transformer 邻居交互模块替换为 MLP。
- **w/o μ-κ Dirichlet**：固定 κ = 30，移除自适应浓度控制。

## 6. 论文的主要结论与发现

- **MAPPO-DM 整体性能最优**：按时投递率 96.40%，丢包率 0.48%（与 w/o Graph Critic 并列最低丢包率）。
- **多路径优于单路径**：所有多路径方法均明显优于 Priority-Aware Greedy Single-Path（按时投递率约 45%，远低于多路径的 75%–96%）。
- **消融分析**：
  - 去除图 Critic 主要损害按时投递率（降至 95.91%）；
  - 去除 Transformer 同时增加丢包（升至 0.84%）；
  - 固定 κ 反而微升按时投递率（96.70%）但丢包率明显上升（1.78%），说明自适应浓度控制有助于降低丢包。
- **鲁棒性**：随热点区域数增多（负载增加），MAPPO-DM 性能下降最慢；随 UAV 数量增加，MAPPO-DM 和 Equal-Split 均受益于更密的拓扑；MAPPO-DM 对 N 的变化不敏感（N=2 后性能基本稳定），而 Capacity-Aware 在 N>4 后性能下降。
- **累计到达比**：MAPPO-DM 在期限前（x=0）累计到达比约 96%，远超所有基线，且上升曲线在期限附近快速攀升，体现对流量紧迫度的良好适应性。

## 7. 优点

- **问题新颖**：首次将逐跳多路径路由引入多跳 UAV 网络，突破传统端到端多路径的局限，学术贡献清晰。
- **建模完整**：将路由问题系统建模为 Dec-POMDP，覆盖通信、队列、转发、干扰、拓扑动态等多方面因素，模型细节扎实（如 EWMA 干扰估计、地理防环机制、多优先级子队列）。
- **算法设计巧妙**：
  - Dirichlet 分布建模连续流量拆分动作，天然满足概率单纯形约束；
  - μ-κ 分离设计实现了“均值决策 + 自适应探索”的平衡；
  - Transformer 建模邻居间交互、GRU 建模时间演化、图注意力 Critic 建模全局拓扑，各组件定位清晰且互补。
- **奖励设计精细**：融合地理进步、拥塞风险、丢包惩罚、本地持有惩罚与全局事件奖励，兼顾局部动作与端到端性能。
- **实现完备**：公开源代码，提供环境与算法全部超参数，实验可复现性好。
