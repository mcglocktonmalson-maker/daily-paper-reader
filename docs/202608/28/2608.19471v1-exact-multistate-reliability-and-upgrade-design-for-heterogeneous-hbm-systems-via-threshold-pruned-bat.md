## 摘要
高带宽存储器（HBM）系统能够表现出部分服务，而不仅仅是完全服务或完全隔离：由于子通道隔离、通道重映射或保护开销，控制器可见的服务单元可能提供完全、降低或零带宽。本文提出了一个精确的多状态可靠性框架，其中每个服务单元携带任意有限的带宽状态集，可靠性是聚合传输带宽满足需求的概率。二进制k-out-of-n模型作为特例被恢复，而闭式二值映射误差关系量化了平均带宽失真，并为更简单的抽象提供了筛选测试。为了进行精确的单阈值评估，提出了一种阈值剪枝的多状态二进制加法树（TP-mBAT）算法。它刻意针对特定场景：在紧凑的公共网格上，固定网格动态规划更可取，其中16个单元的可通约控制需要273次剪枝DP更新，而TP-mBAT需要362,506次节点访问。在可复现的14单元不可通约基准上，TP-mBAT与采用相同阈值规则的动态规划进行比较，从而不削弱任何基线。两者扩展相同的状态空间，6,862个节点对比6,861次更新，区别完全在于保留状态：在中心需求下，17个遍历条目对比412,121个概率状态，将测得的峰值存储从25.02 MB减少到1,152字节。精确的概率转移敏感性识别出将质量从劣化状态转移到更高带宽状态何时会改变系统成功，并且保留单元下限模型允许第三种精确剪枝规则，在没有此类下限时该规则是空洞的。潜在包状态混合捕获了共享应力，忽略依赖性会使可靠性高估8.73个百分点。

## Abstract
High Bandwidth Memory (HBM) systems can exhibit partial service rather than only full service or complete isolation: a controller-visible service unit may deliver full, reduced, or zero bandwidth because of sub-channel isolation, lane remapping, or protection overhead. This paper develops an exact multistate reliability framework in which each service unit carries an arbitrary finite set of bandwidth states and reliability is the probability that aggregate delivered bandwidth meets a demand. The binary k-out-of-n model is recovered as a special case, while closed-form binary-mapping error relations quantify mean-bandwidth distortion and provide a screening test for the simpler abstraction. For exact single-threshold evaluation a threshold-pruned multistate Binary-Addition-Tree (TP-mBAT) algorithm is proposed. It is deliberately regime-specific: fixed-grid dynamic programming is preferable on a compact common grid, where a 16-unit commensurate control required 273 pruned-DP updates versus 362,506 TP-mBAT node visits. On a reproducible 14-unit incommensurate benchmark, TP-mBAT is compared against a dynamic program carrying the same threshold rules, so that no baseline is weakened. Both expand the same state space, 6,862 nodes against 6,861 updates, and the separation lies entirely in retained state: 17 traversal entries against 412,121 probability states at central demand, reducing measured peak storage from 25.02 MB to 1,152 B. An exact probability-transfer sensitivity identifies when moving mass from a degraded state to a higher-bandwidth state changes system success, and a reserved-unit floor model admits a third exact pruning rule that is vacuous without such floors. A latent package-state mixture captures shared stress, where ignoring dependence overstates reliability by 8.73 percentage points.

# 论文总结：通过阈值剪枝的 BAT 实现异构 HBM 系统的精确多状态可靠性与升级设计

## 1. 核心问题与整体含义

- **研究动机**：高带宽存储器（HBM）在 AI 加速器、高性能计算中广泛使用，但其系统级可靠性不是简单的“全好/全坏”二值问题。由于子通道隔离、通道重映射、保护开销等原因，控制器可见的服务单元可能提供**完全带宽、降级带宽或零带宽**。
- **现有模型的不足**：传统二进制 `k-out-of-n` 可靠性模型只把单元看作全带宽或失效两种状态，无法刻画中间降级状态，也无法处理不同单元容量和故障概率不同的异构场景。
- **论文目标**：建立“控制器可见服务单元”层次的**精确多状态可靠性框架**，以“聚合带宽是否满足需求”作为可靠性判据，并进一步解决升级设计、敏感性分析、共享依赖和保留单元下限等问题。
- **整体含义**：这项工作不是完全否定二值模型，而是将二进制模型作为多状态模型的特例（`k-out-of-n` 可被精确恢复），同时针对二值模型失效的场景提供更一般的精确求解方法。

## 2. 方法论

### 2.1 多状态 HBM 服务模型

- 系统共有 $U$ 个控制器可见服务单元，每个单元 $u$ 有任意有限带宽状态集合 $\mathcal{A}_u=\{a_{u,0}=0,\dots,a_{u,L_u}\}$，对应概率 $p_{u,l}$。
- 单元带宽聚合成堆栈带宽 $W_s$，再聚合成系统总带宽 $W_{\text{tot}}$。
- **池化可靠性（pooled reliability）**：$R_{\text{pool}}(D)=\Pr(W_{\text{tot}}\ge D)$。
- 明确区分“池化带宽”与“复制/备选服务”：若多个堆栈是替代关系，则可靠性用 $1-[1-R_{\text{stack}}(\tau)]^S$，不能与池化公式混用。

### 2.2 共享依赖与保留单元

- 引入离散潜在包状态 $H\in\{1,\dots,K\}$，条件独立时无条件可靠性为各条件可靠性的混合：$R_{\text{pool}}(D)=\sum_h \pi_h R_{\text{pool}}(D\mid H=h)$。
- 保留单元（reserved units）$\mathcal{R}$ 有各自的容量下限 $c_u$，可靠性定义为“总带宽满足需求且每个保留单元满足其下限”的联合事件。

### 2.3 精确可靠性计算

- 当所有带宽是公共增量 $\Delta$ 的整数倍时，用概率生成函数 $G_u(z)=\sum_l p_{u,l}z^{d_{u,l}}$ 和卷积/动态规划求精确分布。
- 有依赖时，条件生成函数乘积后按潜在状态加权。
- 二进制 `k-out-of-n` 被证明是该多状态模型在“所有单元同质、仅全带宽/失效两状态”时的特例。

### 2.4 阈值剪枝多状态 BAT（TP-mBAT）

- 核心思想：在混合进制加法树中遍历部分状态，使用两个精确剪枝规则：
  - **成功聚合规则**：若当前累积带宽 $B_r\ge D$，则该分支所有后代都成功，直接把当前分支概率 $P_r$ 累加到可靠性。
  - **失败剪枝规则**：若 $B_r + M_{\text{rem}}(r) < D$（剩余单元最大可能带宽之和仍不足），则该分支全部失败，直接丢弃。
- 在保留单元下限存在时，还有第三条规则：利用未分配保留单元的有效下限 $m_{\text{rem}}(r)$ 和保留概率质量 $\Pi_{\text{rem}}(r)$，若 $B_r+m_{\text{rem}}(r)\ge D$，则分支以 $P_r\cdot\Pi_{\text{rem}}(r)$ 贡献可靠性。
- **复杂度**：TP-mBAT 遍历栈大小有界为 $O(U\cdot L_{\max})$，与存活部分状态数量无关。
- **与动态规划的关系（命题 1）**：采用相同剪枝规则的动态规划（pruned DP）扩展状态数不超过 TP-mBAT；当幸存容量无碰撞时二者扩展数相等。TP-mBAT 的独特优势是遍历存储有界，而 DP 需要保留大量概率状态。
- **升级设计**：给出概率转移敏感性公式，并建立最小成本异构升级优化模型：
  $\min \sum_{u,m} c_{u,m} y_{u,m}$，约束 $R_{\text{pool}}(D;y)\ge R_{\text{tar}}$，每个单元恰好选择一个动作。

## 6. 主要结论与发现

- **算法有效性**：TP-mBAT 在不可通约、单阈值、存储受限场景中优势明显。例如 14 单元中心需求下，TP-mBAT 峰值存储为 1,152 字节（17 个遍历条目），而 pruned DP 需要 412,121 个概率状态、约 25.02 MB。
- **求解器选择边界**：在紧凑公共网格场景（16 单元可通约控制）中，pruned DP 远优于 TP-mBAT（273 次更新对比 362,506 次节点访问），因此应按能力结构和存储需求选择求解器。
- **二进制近似误差**：二值映射会导致明显失真。例如 $\alpha=0.30$ 时乐观二值映射的阈值可靠性误差高达 +30.284%；$\alpha=0.70$ 时保守映射误差达 -17.072%。均值带宽误差不能可靠预测阈值可靠性误差。
- **服务语义差异**：池化带宽与复制/备选服务的可靠性在高需求下严重分歧，最大差距可达 0.72，不能互相替代。
- **共享依赖影响**：忽略共享潜在包状态会把可靠性高估最多 8.725 个百分点（$U=16$，$D=12b$，stressed 概率 0.20）。
- **保留单元下限**：第三个剪枝规则可将节点访问减少最多 64.3%（14 单元全部保留时），同时不增加峰值存储。
- **升级设计**：最小成本升级选择能精确达到目标可靠性，且选择结果依赖单元特性和系统阈值。
- **Monte Carlo 局限**：高可靠场景（$R=0.9998267$）下，100 万样本的 95 分位绝对误差仍约 $1.78\times10^{-5}$，精确算法无采样误差。

## 8. 不足与局限

- **计算复杂性**：精确阈值可靠性本身是 #P-hard 问题，TP-mBAT 最坏情况仍是指数复杂度的，论文也明确该方法不是 DP 的普遍替代。
- **应用场景局限**：只适用于单阈值、不可通约、存储受限等特定情境；在紧凑公共网格或有完整分布需求时，DP 更合适。
- **模型假设限制**：状态概率是静态的，没有连接热/退化/占用的动态演化模型；潜在状态混合是离散有限的，实际共享应力可能更复杂。
- **缺乏真实数据验证**：所有实验基于合成基准，没有使用真实 HBM 错误记录或现场数据，外部有效性仍需检验。
- **二值筛查测试局限**：均值带宽误差公式只能过滤“平均带宽失真”，不能直接判断阈值可靠性误差，论文自己也给出了反例。
- **性能报告依赖平台**：墙钟时间和内存字节是实测值，受容器、分配策略和编译器影响，不能作为跨平台绝对结论。
- **升级优化规模有限**：示例仅 8 个单元，对更大规模升级问题的可扩展性未充分讨论。
