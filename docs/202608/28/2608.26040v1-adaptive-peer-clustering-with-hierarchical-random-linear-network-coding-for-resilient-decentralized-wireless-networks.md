## 摘要
去中心化无线集群，包括车辆群体、物联网集群和边缘AI网络，需要能够在动态拓扑和异构链路质量下保持鲁棒性的通信协议。虽然随机线性网络编码（RLNC）提供了针对数据包擦除的代数弹性，但当对等节点表现出多样化的信道条件时，其性能会显著下降。本文提出了一种自适应对等聚类与分层RLNC（APC-RLNC）系统，该系统通过指数加权移动平均（EWMA）可靠性指标动态地对对等节点进行分组，并在簇内和簇间应用多层级网络编码。我们形式化了聚类优化问题，推导了马尔可夫擦除信道的闭式解码概率界，并证明了在跟随正则化领导者（FTRL）框架下在线重配置的O(√T)遗憾界。我们的实现包括高保真网络模拟器和在Jetson Nano边缘设备上部署的概念验证测试平台。在包括高移动性车辆网络、突发错误信道和对抗性干扰在内的多种场景下的评估表明，与最先进的基线相比，数据包投递率（PDR）提高了5.2-9.8个百分点，延迟降低了10-23%，节点保持率提高了高达30%。该系统展现出对500+节点的线性可扩展性，并将实时重配置开销保持在3%以下。APC-RLNC确立了自适应聚类作为AI原生6G无线系统的基础原语。

## Abstract
Decentralized wireless collectives including vehicular swarms, IoT clusters, and edge AI networks require communication protocols that maintain robustness under dynamic topologies and heterogeneous link quality. While Random Linear Network Coding (RLNC) provides algebraic resilience against packet erasures, its performance degrades significantly when peers exhibit diverse channel conditions. This paper presents Adaptive Peer Clustering with Hierarchical RLNC (APC-RLNC), a system that dynamically groups peers by exponentially weighted moving average (EWMA) reliability metrics and applies multi-tier network coding within and across clusters. We formalize the clustering optimization problem, derive closed-form decoding probability bounds for Markov erasure channels, and prove O(sqrt(T)) regret for online reconfiguration under the Follow-the-Regularized-Leader (FTRL) framework. Our implementation includes both a high-fidelity network simulator and a proof-of-concept testbed deployment on Jetson Nano edge devices. Evaluation across diverse scenarios including high-mobility vehicular networks, burst-error channels, and adversarial interference demonstrates 5.2-9.8 percentage-point packet delivery ratio (PDR) improvements, 10-23% latency reductions, and up to 30% higher node retention compared to state-of-the-art baselines. The system exhibits linear scalability to 500+ nodes and maintains real-time reconfiguration overhead below 3%. APC-RLNC establishes adaptive clustering as a foundational primitive for AI-native 6G wireless systems.

### 一、核心问题与整体含义（研究动机与背景）

去中心化无线集群（如车辆自组网、物联网集群、边缘AI网络）的通信协议需在动态拓扑与异构链路条件下保持鲁棒性。传统随机线性网络编码（RLNC）虽能有效对抗数据包擦除，但其隐含假设所有接收端经历相同的信道擦除率，该假设在真实异构场景中不成立：

- **异构链路质量**：受移动、衰落、多径和干扰影响，信道擦除概率可能相差数量级；
- **动态拓扑（节点流转）**：典型流转率高达每传输轮次 2–10%，静态冗余策略失效；
- **能量与规模约束**：边缘设备功率受限（常低于 5W），却需协调数百至数千节点。

上述问题导致高可靠节点浪费带宽于过度冗余，低可靠节点却得不到足够保护，引发吞吐量崩溃与公平性受损。本文提出 **自适应对等聚类与分层RLNC（APC-RLNC）** 系统，将按链路可靠性聚类作为编码层原语，以应对上述三方面挑战，并作为 AI 原生 6G 无线系统的基础构件。

### 二、方法论：核心思想、关键技术细节与公式/算法流程

#### 2.1 核心思想

将节点按链路可靠性（EWMA 平滑后的丢包统计）动态聚类，簇内执行定制冗余度的 RLNC，簇间通过桥接编码包提供二次保护。这样做的好处：减少冗余浪费、支持分布式扩展（O(N log N)）、实现故障隔离。

#### 2.2 关键技术细节

**系统模型与信道模型：**
- 拓扑建模为无向图 \(G_t=(V_t, E_t)\)，链路擦除率 \(p_{ij}(t)\) 时变；
- 路径损耗模型：\(p_{ij}(t)=\min(1, p_0(d_{ij}/d_0)^\alpha)\)，\(\alpha=3.5\)；
- 三种信道模型：Bernoulli、2态 Markov（好/坏状态转移概率 0.10）、速度相关衰落（\(p_i(t)=p_{\text{base}}+\beta \cdot |v_i(t)|\)）；
- 节点流转服从 Poisson 过程，速率 \(\rho_{\text{churn}} \in [0.02, 0.10]\)。

**可靠性评分（EWMA）：**
\[
s_i(t) = \alpha \ell_i(t) + (1-\alpha) s_i(t-1), \quad \alpha=0.2
\]
其中 \(\ell_i(t)\) 为瞬时包成功率。

**聚类优化目标：**
\[
L(C_{1:C}, t) = \sum_{c=1}^{C} \left[ \text{Var}_{i\in C_c}[s_i(t)] - \lambda |C_c| \right]
\]
该目标同时惩罚簇内异质性（第一项）与奖励簇规模（第二项），防止过度碎片化。

**分层RLNC：**
- 簇内冗余 \(R_c = \lceil \beta |C_c| \bar{p}^{\text{erase}}_c \rceil\)，\(\beta\ge1\) 为安全裕度；
- 簇间桥接包 \(b_j = \sum_{c=1}^{C} \gamma_{j,c} \cdot \text{Summary}_c\)，桥接冗余与簇间异质性成正比：\(R_{\text{bridge}} = \lceil 0.5 \cdot C \cdot \text{Var}(\{\bar{p}_c\}) \rceil\)；
- 解码成功条件：全局收到至少 K 个线性无关的编码包。

**分布式聚类算法（Algorithm 1）：** 基于 Gossip 共识 + k-means（\(k=\lfloor \sqrt{N}/2 \rfloor\)），每 \(\tau\) 步执行一次，O(log N) 轮内收敛。

**Byzantine 防御：** 中位数均值聚合 + 马氏距离异常检测（>3σ 隔离恶意节点，容忍 <1/3 恶意节点）。

#### 2.3 核心理论结果

- **定理1（分层解码概率）**：\(P_{\text{sys}} = 1 - \prod_{c=1}^{C}(1 - P^{(c)}_{\text{succ}})\)。示例：单簇 \(P^{(c)}_{\text{succ}}\approx0.971\)（K=32，R_c=16，\(\bar{p}_c=0.225\)），C=5 时 \(P_{\text{sys}}\approx0.99999998\)。
- **定理2（在线聚类遗憾界）**：FTRL 算法 + 平方欧氏正则化，在 Lipschitz 常数 G 下达到 \(\text{Regret}(T) \le G^2\sqrt{2T}\)，即 O(√T) 遗憾。
- **复杂度**：聚类 O(Nk)、单簇编码 O(K²)、总编码 O(CK²)、单簇解码 O(K³)。

### 六、主要结论与发现

1. **名义条件（30节点）**：APC-RLNC 相比 Random 提升 0.8 个百分点 PDR（相对 0.82%）、延迟降低 10%、节点保留率提升 20%。
