## Abstract
This paper presents a novel two-phase maskable proximal policy optimization (TP-MPPO) algorithm, which maximizes the system goodput counting request throughput with strict service level objective (SLO) compliance for large language model (LLM) inference services in wireless edge networks. In the first phase of TP-MPPO, we optimize the task offloading decisions by MPPO with action masking mechanism, effectively avoiding exploring invalid actions and reducing the action space. In the second phase, closed-form solutions are derived for uplink bandwidth allocation; a greedy algorithm is designed for downlink bandwidth allocation to provide immediate rewards for the MPPO in the next round. The two stages alternate till convergence. Simulation results demonstrate that TP-MPPO can improve the system reward by 33.3%--87.5% compared to its benchmarks and achieve the highest goodput.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想：两阶段交替优化

TP-MPPO 将原始的混合整数非线性规划（MINLP）问题 P1 解耦为两个阶段，交替迭代直至收敛：

- **第一阶段**：利用带动作掩蔽机制的 MPPO 学习任务卸载决策（将请求分配给哪个边缘节点或拒绝）；
- **第二阶段**：给定卸载决策后，将剩余的带宽分配问题进一步分解为上行和下行两个子问题：
  - 上行带宽分配推导出**闭式解**；
  - 下行带宽分配通过**贪心算法**求解。

两个阶段交替执行：第二阶段为第一阶段提供即时奖励信号，驱动策略稳定收敛。

### 2.2 问题建模：P1 的目标与约束

$$\text{P1:}\quad \max_{\{\boldsymbol{\alpha}^t, \boldsymbol{\beta}^{up,t}, \boldsymbol{\beta}^{down,t}\}} \mathcal{Y}'$$

约束条件包括：

- **带宽约束**：每个边缘节点的上行和下行带宽分配分数之和不超过 1；
- **内存约束**：边缘节点的内存占用（模型权重 + KV 缓存）不超过其 GPU 显存容量 \( M_j \)。

该问题是 NP-hard 的 MINLP，包含非凸、离散的二元决策变量，且 LLM 批推理导致用户间存在强耦合（批的延迟与内存取决于具体任务组合）。

### 2.3 MPPO 阶段（卸载决策）

- **状态空间**：\( s_t = \{q_t^n,\ h^{up,t}_{nj},\ h^{down,t}_{nj},\ I_t^j,\ \forall n,j\} \)，其中 \( I_t^j \) 表示节点 j 是否空闲。
- **动作空间与掩蔽**：为每个用户动态生成二元掩码向量 \( v_t^n \)，若请求存在且节点空闲则为 1，否则为 0。在 Actor 网络前向传播时将无效动作的 logits 置为 \(-\infty\)，Softmax 后概率为 0，从根本上杜绝无效动作的探索。
- **奖励函数**：
  $$r_t = \nu_{\text{good}} \frac{\sum_{n\in\mathcal{N}} g_t^n}{N_{\text{req},t}} - \nu_{\text{oom}} \frac{N_{\text{oom},t}}{N_{\text{req},t}}$$
  即归一化的 goodput 贡献减去归一化的 OOM 失败惩罚，\( \nu_{\text{good}} \) 和 \( \nu_{\text{oom}} \) 为权重系数。
- **更新方式**：采用 PPO 的 clip 目标函数和广义优势估计（GAE），行为网络与目标网络分离，从经验回放缓冲区采样更新。

### 2.4 上行带宽分配：闭式解（P2）

给定卸载决策后，上行分配的目标是**最小化批内最大上行传输延迟**（即最大-最小公平）。根据 min-max 公平原则，最优策略是让批内所有用户的上行延迟相等，由此推导出闭式解：

$$\left(\beta^{up,t}_{nj}\right)^* = \frac{D^{in,t}_n / R^{up,t}_{nj}}{\sum_{i\in\mathcal{N}_t^j} \left(D^{in,t}_i / R^{up,t}_{ij}\right)}$$

即按各用户数据量与速率的比值进行归一化分配。

### 2.5 下行带宽分配：贪心算法（P3）

- 首先根据 SLO 剩余时间计算每个用户所需的最小下行带宽分数：
$$\beta^{down,t}_{nj,\min} = \frac{D^{out,t}_n}{T^{re,t}_n \cdot B^{down}_j \log_2\left(1 + \frac{p^{down,t}_{nj} h^{down,t}_{nj}}{\psi'}\right)}$$
- 问题转化为：在总带宽不超过 1 的约束下，选择最大的用户子集。
- 由于所有被选用户对 goodput 的贡献相等（都为 1），**Algorithm 1** 提出按最小带宽需求升序排序，逐个贪心加入直至带宽耗尽，作者证明该方法达到零最优间隙，复杂度为 \(O(N\log N)\)。

## 6. 论文的主要结论与发现

1. **奖励性能提升显著**：TP-MPPO 相比 MPPO、TP-PPO、Rewardless 分别提升系统奖励 **33.3%、87.5%、71.4%**，并展现最快的收敛速度（约 200 episodes）。
2. **动作掩蔽有效**：TP-MPPO 和 MPPO（均带掩蔽）收敛快于无掩蔽的 TP-PPO，说明掩蔽机制消除了无效动作探索，显著提升样本效率。
3. **goodput 最高的模型更大时差距拉大**：模型越大，吞吐量与 goodput 之间的差距越大（如 Llama-7B），因为计算和内存需求高会增加 SLO 违约和 OOM 失败，突出了 goodput 导向的分配策略对服务可靠性的重要性。
4. **不同网络配置下均占优**：
   - 6 节点、20 用户时，TP-MPPO 比 MPPO、TP-PPO、Heuristic、Rewardless 的 goodput 比率分别高 5.4%、9.5%、7.1%、10.2%；
   - 3 节点、30 用户时，分别高 3%、7.3%、6.5%、7%。
5. **GPU 资源增加时优势保持**：在 Llama-30B 下，GPU 资源提高时 TP-MPPO 将 goodput 比率从 42.0% 提升至 60.7%，显著优于基准。
6. **两阶段分解的有效性**：有限闭式解 + 贪心算法的第二阶段为第一阶段 MPPO 提供即时奖励，是驱动策略稳定收敛的关键设计。

- **训练算力信息缺失**：论文未披露训练阶段所用 GPU 型号、数量、总训练时长及能耗，可复现性较低。此信息对于衡量算法实用性及对比其他 RL 方法的训练成本至关重要。
- **仿真场景规模有限**：所有实验均在仿真环境中进行，且网络规模较小（最多 30 用户、6 节点）。无线信道模型的简化（固定路径损耗指数、静态信道、理想信道估计）与真实动态无线环境存在差距，限制了结论向真实系统推广的可信度。
- **缺乏消融实验**：虽然动作掩蔽的有效性可通过对比 TP-PPO 得到间接验证，但论文未显式设置消融组来独立量化掩蔽机制、奖励函数中 \(\nu_{\text{good}}/\nu_{\text{oom}}\) 权重、两阶段分解结构等各自对最终性能的贡献，使得“究竟是哪个组件起到了决定性作用”这一问题缺乏细粒度的归因。
- **SLO 设定过于简化**：各用户的 SLO 仅与输入序列长度关联（128→3 s，256→5 s，512→9 s），未建模不同应用中 SLO 类型的多样性（如流式交互应用对 TPOT 极敏感，离线批处理则仅关心 E2E），也未考虑 SLO 在时间上的动态变化。
- **未考虑多请求批处理的内部调度细节**：论文虽然建模了批推理延迟与 KV 缓存的关系，但未涉及批内请求的优先级调度、FCFS 与短作业优先等策略对 SLO 满足率的影响；KV 缓存共享或分页（如 PagedAttention）等现代技术也未纳入模型。
- **上行/下行解耦假设**：本文假设上下行带宽分配可独立求解，但实际中用户的上行传输与下行结果返回共用同一物理链路带宽，尤其在时分双工系统中，二者存在耦合，该简化工况可能在实际部署中失效。
- **未讨论能量与成本约束**：边缘节点 GPU 的能耗以及当多个节点同时被选择时的负载均衡成本并未纳入优化目标，在真实边缘网络中，运行成本往往与服务质量同等重要。

## 9. 个人评价与启发

TP-MPPO 是边缘 LLM 推理调度中较早系统性地将“goodput”作为优化目标的强化学习方法之一，其核心贡献主要体现在三个层面：

**方法层面**：为“RL 处理离散组合优化 + 数学优化处理连续资源分配”的混合结构提供了可借鉴的模板。两阶段交替优化的框架不仅适用于 LLM 卸载问题，也可以迁移至其他 NP-hard 的服务调度场景（如边缘视频分析、模型分片推理等）。

**约束处理层面**：动作掩蔽机制在 RL 中的使用并不罕见，但本文将其与动态节点空闲状态、请求存在性相结合，且将掩蔽向量作为状态的一部分输入网络，这一“状态感知掩蔽”的工程实现方式值得借鉴。

**指标设计层面**：明确指出吞吐量与 goodput 之间的本质区别——在高计算需求任务下（模型越大、输出越长），传输速率和计算速率的不匹配会导致大量请求因超出 SLO 而被“空跑”，goodput 才能真正反映系统的有效服务水平。

**可能存在的技术争论点**：在训练阶段，MPPO 所需的经验回放缓冲区在面对用户规模扩大到百级、节点扩展至数十个时，状态空间的维度组合将急剧膨胀，是否依然能保持 200 episodes 的收敛速度值得怀疑；此外，\(\nu_{\text{good}}\) 和 \(\nu_{\text{oom}}\) 两个奖励权重的选取对收敛性能的影响未做敏感性分析，若因场景变化需重新调参，算法的鲁棒性将受到挑战。

**未来研究方向**：

1. 将 TP-MPPO 推广至多级边缘-云协同推理场景，引入模型分片（如 LLM 层级按需切分）以进一步扩展系统容量；
2. 引入真实无线信道测量数据驱动的仿真环境，验证算法在动态信道和干扰条件下的鲁棒性；
3. 探索将 KV 缓存的页面式管理及显存预分配策略作为新的约束嵌入问题模型，提高内存约束的建模精度；
4. 考虑多用户多任务类型（文本生成、摘要、代码生成）并存时的差异化服务保障机制。

---

**总结**：TP-MPPO 通过巧妙的“两阶段分解 + 强化学习 + 闭式解/贪心算法”的组合拳，在一个被既有文献长期忽略的指标——goodput——上取得了显著的性能提升，是边缘 LLM 推理调度方向上的一个重要推进。尽管在真实场景验证、消融实验及算力透明度上存在不足，但其方法论框架和实验设计思路对后续研究具有较高的参考价值。若作者能在未来工作中弥补仿真规模与消融分析的缺陷，该工作的学术与工程影响力将进一步扩大。
