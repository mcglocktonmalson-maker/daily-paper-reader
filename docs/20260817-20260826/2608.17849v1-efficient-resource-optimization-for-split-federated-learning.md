## 摘要
分割联邦学习（SFL）已成为边缘模型训练的一种强大范式。然而，SFL本质上涉及模型分割和资源分配的离散决策变量，导致一个具有挑战性的混合整数问题。因此，先前的SFL优化方案要么是启发式的，要么是计算效率低下的，无法处理大规模用户群体。为了解决这一局限性，本工作在资源受限网络下为SFL建立了一个高效的优化框架。我们的框架联合优化模型分割和资源分配以最小化训练成本，该成本定义为延迟和能量成本的加权和。我们首先研究模型分割问题，并开发一种实现全局最优的多项式时间算法。然后，我们将该方法扩展到联合模型分割和资源分配问题。在这种情况下，我们将其表述为一个二维主问题，并开发了一种具有(1+ε)近似保证的高效近似方法。大量实验表明，所提出的方法为达成最优的能量-延迟权衡提供了高效的解决方案。

## Abstract
Split federated learning (SFL) has emerged as a powerful paradigm for model training at the edge. However, SFL inherently involves discrete decision variables for model splitting and resource allocation, resulting in a challenging mixed-integer problem. Consequently, prior optimization schemes for SFL are either \textit{heuristic} or \textit{computationally inefficient}, which cannot handle large-scale user populations. To address this limitation, this work establishes an efficient optimization framework for SFL under resource-constrained networks. Our framework jointly optimizes model splitting and resource allocation to minimize training cost, which is defined as the weighted sum of latency and energy costs. We first study the model splitting problem and develop a polynomial-time algorithm that achieves the global optimum. Then, we extend the approach to the joint model splitting and resource allocation problem. In this case, we formulate it as a two-dimensional master problem and develop an efficient approximation method with a $(1+ε)$-approximation guarantee. Extensive experiments show that the proposed approach provides efficient solutions to strike the optimal energy--latency tradeoff.

- **研究背景**：边缘学习需要在靠近数据源的位置执行AI计算，以保护隐私、节省带宽并支持个性化服务。然而现代大模型对算力要求极高，甚至NVIDIA Jetson AGX Xavier也难以训练超过5000万参数的模型。
- **分割联邦学习（SFL）的提出**：SFL将模型划分为客户端侧子模型与服务器侧子模型，客户端在本地数据上完成前向/反向传播的一部分，再将中间激活值或梯度与边缘服务器交换，同时由联邦服务器周期聚合客户端侧子模型参数，从而缓解客户端硬件资源不足的问题。
- **核心问题**：SFL的性能高度依赖于模型分割、GPU频率调节、传输功率、带宽分配等决策的协同优化。但由于模型分割是离散决策变量，资源分配是连续变量，联合优化构成复杂的**混合整数问题**。现有方案要么是启发式的，要么计算复杂度高，难以扩展至大规模用户群体（如数百个用户以上）。
- **本文回答的两个研究问题**：
  - **Q1**：SFL中的模型分割优化能否在多项式时间内精确求解？
  - **Q2**：模型分割、GPU频率缩放和传输功率控制能否在一个统一框架内联合优化？

## 二、论文提出的方法论

### 核心思想
将SFL训练过程建模为客户端侧FP、上行激活传输、服务器侧FP/BP、下行梯度传输、客户端侧BP的五阶段流水线，构造加权和形式的训练成本（能量 + λ × 延迟）作为优化目标，并分别处理离散切层选择与连续资源控制。

### 关键技术细节

1. **系统建模**
   - 每个客户端i的五阶段服务时间由计算量ρ_l、ϖ_l、GPU频率f、带宽B、发射功率P、信道增益h等决定；每轮延迟由两个max项（客户端FP+上行、下行+客户端BP）和一个求和项（服务器侧串行计算）组成。
   - 能量模型包含计算能量（与频率立方相关）和通信能量（与功率和时长相关）。

2. **问题变换**
   - 引入epigraph变量`T1 = max_i(s_i,1 + s_i,2)`、`T2 = max_i(s_i,4 + s_i,5)`，消除max项，将原问题P1变换为P2，包含二进制切层变量y_i,ℓ和服务时间变量s_i,j。

3. **仅模型分割的特殊情形（P3）**
   - 固定资源参数后，每个候选切层对应确定的时长和能量。
   - 设计**Algorithm 1（平面扫描+剪枝）**：枚举候选阈值`T1 ∈ {S_i,1^(ℓ) + S_i,2^(ℓ)}`、`T2 ∈ {S_i,4^(ℓ) + S_i,5^(ℓ)}`，在固定T2下按升序扫描T1，维护每个客户端当前最优可行切层，并在满足剪枝条件（λ(τ_{1,k+1} − τ_{1,k}) > G − G_min）时提前终止扫描。
   - **定理1**证明该算法返回全局最优解，时间复杂度为O(N²L²)，即多项式时间可解。

4. **联合优化的一般情形（P2 → P5）**
   - 固定(T1,T2)后，客户端间解耦，得到每个客户端的价值函数`V_i(T1,T2) = min_ℓ [ U_i,12^(ℓ)(T1) + U_i,45^(ℓ)(T2) + U_i,3^(ℓ) ]`，其中三个内部子问题均为凸优化问题（计算阶段能量函数形如`a/s²`，通信阶段能量函数形如`b·s·(2^(c/s)−1)`，均凸）。
   - 由此将P2**精确等价**地转化为二维主问题`min J(T1,T2) = λ(T1+T2) + Σ_i V_i(T1,T2)`。
   - **Algorithm 2（网格搜索近似）**：在有界矩形`[T1_min,T1_max]×[T2_min,T2_max]`上均匀取网格点，对每个网格点求解各客户端内部子问题并取最小，最终返回最优网格点。
   - **定理3**给出相对误差界：若网格步长Δ满足`Δ ≤ (ε/2)(T1_min+T2_min)`，则网格解满足`J_grid ≤ (1+ε)J*`。
   - **定理4**给出复杂度O((NL/ε²)·log(1/η))，为多项式时间。

5. **控制输入恢复**
   - 得到最优切层和服务时间后，按阶段求解`u*_i,j(s*_i,j) = argmin ψ_i,j(u_i,j, s*_i,j, L*_c,i)`，恢复GPU频率和发射功率的最优控制策略。

## 六、论文的主要结论与发现

1. **模型分割问题可多项式时间精确求解**：Algorithm 1通过枚举候选阈值+剪枝，以O(N²L²)复杂度获得全局最优，回答了Q1。
2. **联合优化问题可高效近似求解**：通过将原问题精确等价转换为二维主问题并施加网格搜索，获得(1+ε)近似保证，多项式复杂度随客户端数线性（在固定ε下），回答了Q2。
3. **性能和可扩展性优势**：OC+OGP在所有测试数据集、模型、带宽和频率设置下均获最低总成本；在500客户端规模下，OC+OGP运行时间远低于ESFL和DSQL，且成本优势保持。
