## 摘要
我们展示了如何将任意经典电路编译成容错电路，即使在每个时间步中几乎线性数量的比特被对抗性选择和破坏，该电路仍能执行所需的计算。利用这种容错方案的一种变体，仅检测（而非纠正）破坏，我们为NP构造了新的概率可检验证明（PCP），其查询复杂度为多对数级别。这种基于容错的PCP构造为Anshu、Breuckmann和Nguyen（STOC'24）的工作提供了一个有前景的量子化候选方案，他们提出了通过容错构造量子PCP的路线图。

## Abstract
We show how to compile an arbitrary classical circuit into a fault-tolerant circuit, which performs the desired computation even when an almost-linear number of bits are adversarially chosen and corrupted in each timestep. Using a variant of this fault-tolerance scheme that only detects (rather than corrects) corruptions, we give a new construction of probabilistically checkable proofs (PCPs) for NP with polylogarithmic query complexity. This PCP construction from fault-tolerance presents a promising candidate for quantization by the work of Anshu, Breuckmann, and Nguyen (STOC'24), who provided a roadmap for constructing quantum PCPs via fault-tolerance.

- **核心编码**：采用 Reed-Solomon 码的 `u` 次张量积，记为 `RS(q,k,E)^{⊗u}`。该码支持分量式乘法（transversal multiplication）：两个码字的逐点乘积属于更高维的 `RS(q,2k-1,E)^{⊗u}`。

- **错误处理**：
  - **容错方案**：使用逐方向的错误纠正器（基于 Welch-Berlekamp 译码器），关键引理证明该纠正过程能纠正比引入更多的错误，可容忍 `|N|/2^{O((log |N|)^{2/3})}` 个错误。

- **电路编译**：利用 Batcher 排序网络将任意逻辑电路转化为“超立方连通”结构，使得每个时间步只需执行沿某个方向的 transversal 门。

- **PCP 构造**：
  - 将待验证电路 `R` 转化为常数深度电路 `\bar{R}`，其输入是 `R` 的执行轨迹（transcript），输出全 0 当且仅当轨迹对应的计算输出为 0。
  - 对 `\bar{R}` 应用故障检测方案，得到物理电路 `R'`。
  - 构造 CSP 实例：变量对应 `R'` 轨迹中所有时空位置的比特；约束分为三类：门执行正确性约束、检测器比特为 0 的约束、输出比特为 0 的约束。
  - 完备性：无噪声运行时所有约束满足。可靠性：若大量约束被违反，则说明错误量过大，故障检测机制会被触发；若错误量小，则输出必须接近某个合法编码的输出，而该输出对应一个真实的 `R(x)=0` 的输入。
