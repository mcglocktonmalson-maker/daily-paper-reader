## 摘要
人工智能生成内容（AIGC）服务利用生成式人工智能（GenAI）模型自动生成多样化内容。移动AIGC网络将GenAI模型托管在边缘位置的AIGC服务提供商（ASP）上，以便为移动用户提供低延迟和个性化的AIGC服务。然而，AIGC推理任务通常在任务完成前一直占用GPU内存，导致服务ASP处GPU内存耗尽，并引发内存溢出故障，而不仅仅是增加服务延迟。现有关于AIGC任务编排的研究大多忽略了GPU内存可行性约束。为解决这一问题，我们开发了一个协作式多智能体编排框架，其中每个边缘节点配备一个调度智能体，将任务路由到本地ASP或相邻边缘节点。由于调度智能体仅基于本地观测做出决策，而同伴卸载会耦合其资源状态和长期效用，我们将编排过程建模为协作式去中心化部分可观测马尔可夫决策过程（Dec-POMDP）。为解决该Dec-POMDP，我们提出了在集中训练与去中心化执行范式下的\underline{注}意力引导的\underline{多}智能体\underline{深}度强化学习算法（带\underline{扩}散策略，A-MADiff）。A-MADiff利用基于扩散的去中心化actor在可行编排动作上生成多模态偏好，并利用注意力引导的集中式critic在GPU内存异构性下从跨智能体状态估计每个智能体的价值。数值结果表明，A-MADiff相比最先进的基线显著提高了累积奖励。

## Abstract
Artificial Intelligence-Generated Content (AIGC) services employ Generative AI (GenAI) models to automatically generate diverse content. Mobile AIGC networks host GenAI models on edge-located AIGC Service Providers (ASPs) to deliver low-latency and personalized AIGC services for mobile users. However, AIGC inference tasks typically occupy GPU memory until task completion, causing GPU memory exhaustion at serving ASPs and triggering out-of-memory failures rather than merely increasing service latency. Existing studies on AIGC task orchestration have largely overlooked GPU memory feasibility constraints. To address this issue, we develop a cooperative multi-agent orchestration framework, in which each edge node is equipped with a scheduling agent to route tasks to local ASPs or neighboring edge nodes. Since scheduling agents make decisions based only on local observations, while peer offloading couples their resource states and long-term utilities, we formulate the orchestration process as a cooperative Decentralized Partially Observable Markov Decision Process (Dec-POMDP). To solve the Dec-POMDP, we propose an \underline{A}ttention-guided \underline{M}ulti-\underline{A}gent deep reinforcement learning algorithm with \underline{Diff}usion policies (A-MADiff) under the centralized training with a decentralized execution paradigm. A-MADiff employs diffusion-based decentralized actors to generate multi-modal preferences over feasible orchestration actions, and an attention-guided centralized critic to estimate per-agent values from cross-agent states under GPU memory heterogeneity. Numerical results demonstrate that A-MADiff significantly improves the cumulative reward over the state-of-the-art baseline.

- **背景**：移动AIGC网络将GenAI模型部署在边缘AIGC服务提供商（ASP）上，为用户提供低延迟、个性化的内容生成服务（如文生图、虚拟人合成、对话助手等）。
- **核心问题**：AIGC推理任务在GPU上执行时，模型权重、KV缓存和中间激活会持续占用GPU内存直至任务完成。当运行时可用的GPU内存不足时，任务会直接触发**内存溢出（OOM）故障**，而非仅仅增加时延。现有AIGC任务编排研究大多只考虑计算资源、带宽、时延等软性约束，而**忽略了GPU内存可行性这一硬性约束**，导致内存耗尽问题在分布式边缘场景中被系统性忽视。
- **难点**：在分布式移动AIGC网络中，每个边缘节点的调度智能体仅拥有局部观测信息，而任务卸载会使节点间的资源状态和长期收益相互耦合；同时GPU内存容量在节点间具有异构性。因此，任务编排本质上是一个**部分可观测条件下的多智能体协作决策问题**，传统单智能体或完全可观测方法难以适用。
- **整体意义**：本文首次将GPU内存可行性作为硬约束引入分布式AIGC任务编排的建模中，并提出了一种新的多智能体深度强化学习算法（A-MADiff），在保证内存约束的前提下优化长期网络效用，为移动AIGC网络的可靠服务提供了新的解决方案。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **问题建模**：
  - 将移动AIGC网络中的任务编排建模为**协作式去中心化部分可观测马尔可夫决策过程（Dec-POMDP）**，即元组 `M = ⟨N, S, {O_n}, {A_n}, P, Ω, R, γ⟩`。

    - 运行时可行性：仅当ASP的可用GPU内存 `M_av >= m_i` 时任务才能开始执行；否则触发OOM故障并施加失败惩罚。
  - 奖励函数设计：本地执行奖励为服务效用减去执行时延成本；卸载奖励为估算路由效用减去通信时延和估算执行时延；延迟动作有固定成本；违规动作给失败惩罚。

- **A-MADiff算法（核心思想）**：
  - 遵循**集中式训练、去中心化执行（CTDE）**范式。
  - **扩散策略actor**：每个智能体的策略由条件扩散模型表示。从高斯噪声开始，经过多步反向去噪（reverse denoising），结合局部观测和扩散步长，生成状态条件化的离散动作偏好；再通过可行性掩码进行softmax归一化，保证只采样结构可行动作。扩散模型能刻画多模态的复杂动作偏好，优于单层MLP的高斯/分类策略。
  - **注意力引导的集中式critic**：用于估计每个智能体的边际动作价值（而非联合动作价值）。critic对多智能体的局部观测进行编码，使用多头自注意力（MHA）自适应加权跨智能体状态信息，结合智能体one-hot身份向量，输出每个动作的价值估计。双critic结构用于缓解Q值过估计。
  - **训练与更新**：采用SAC风格的熵正则化离策略学习。Critic通过最小化TD误差更新（公式38），Actor通过最大化高价值动作概率并维持熵（公式39），熵系数自动调整（公式41），目标网络软更新（公式42）。
  - **执行阶段**：仅使用扩散actor和可行性掩码，各智能体基于局部观测独立决策，不依赖critic；复杂度为 `O(N·Td·dh^2 + N·Td·A·dh)`。
